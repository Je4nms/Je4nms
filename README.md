## Projetos

### [NorthFinance](https://github.com/Je4nms/northfinance) · [abrir o app](https://northfinance.vercel.app)
O app de finanças mais simples que existe. Comecei em Python para validar a ideia e reconstruí como **app instalável** em TypeScript, usando o mesmo banco de dados.

- Login com Google, convite por código e dados separados por pessoa
- Meta do mês, gastos fixos lançados automaticamente, gráfico de gastos por dia
- Segurança (CSP, limite de tentativas, validação no servidor) e acessibilidade (tamanho do texto, alto contraste)
- **Next.js · TypeScript · Tailwind · PostgreSQL · Auth.js · Vercel** (v1: Python + Streamlit)

### [Moodscape](https://github.com/Je4nms/moodscape) · [abrir o app](https://moodscape-je4nms.streamlit.app)
Conecta no Spotify e desenha o mapa de humor do seu gosto musical. Projeto de dados: integrei duas fontes, medi a cobertura e documentei os limites dos dados.

- Login com Spotify (OAuth), API externa e base de 90 mil músicas consultada com SQL
- **Python · Streamlit · SQL (DuckDB) · Altair**
